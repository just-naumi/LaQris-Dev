# LaQris-Dev 

**LaQris (QRIS Fraud Detection & Evidence-Based Merchant Reputation System)**

Sistem deteksi kecurangan stiker QRIS yang ditimpa (physical vs digital identity matching) serta kalkulasi EMRS (*Evidence-Based Merchant Reputation Score*).

## Fitur Utama
- **Physical Identity Extraction**: Dual YOLO + TrOCR untuk membaca nama merchant dan QRIS dari stiker fisik.
- **EMVCo QR Parsing**: Parsing data QRIS digital.
- **Identity Matching**: Verifikasi kesesuaian data fisik dan digital.
- **EMRS Reputation Engine**: Sistem reputasi merchant berbasis bukti & laporan pengguna.
